## 4 发布口径（M6 用，本棒只登记）

### 4.1 发布物形态

**手工源码包**（`git archive` 口径），不是 GitHub 自动生成的 Source code 包——
后者的 sha256 本地复算不出来。附件 `mailvault-1.0.0.tar.gz` 由 CI 从 tag 树构建。

### 4.2 版本"三处一致"

| 处 | 判据 |
|---|---|
| `mailvault/__init__.py::__version__` | **唯一真源** |
| `pyproject.toml` | `dynamic = ["version"]` + `attr = "mailvault.__version__"`（不写第二份） |
| `README.md` 状态行 | 含 `v${version}` |

一条测试同时断言三处（M6 落地 `tests/test_version_consistency.py`）。

### 4.3 tag 后纪律

- `POST_TAG_SCOPE`：改动 ⊆ 非交付面（`plan/` `tests/` `tools/` `docs/` `README` `AGENTS`）
- `DELIVERABLE_UNCHANGED`：交付面前缀（`mailvault/` `pyproject.toml`）**零差异**
- tag 树内的留档**不写** tag 的 OID / 包 sha256（自指，写一次失效一次）；字面值放 tag 之后

### 4.4 CI 口径（本棒不建远端）

未推送 = 未跑 CI。M0 的 DoD 里**不写"CI 绿"**，只写：

> 本地等价校验（未接远端，CI 待首推验证）：布局门全绿 + 10 组变异变红 + AST 守门 + `pytest` 全绿 + CLI 冒烟。

首次推送后回填 run id 与 `push 数 = run 数` 对账结果。
