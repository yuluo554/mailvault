## 4 风险登记

| 风险 | 触发条件 | 缓解 | 责任人 |
|---|---|---|---|
| R1 定位被读成"离线重放" | README 卖点写偏 | 已写两条显式否定（不承诺进箱 / 不卖离线）；M6 禁词门 | 作者 |
| R2 新标准护城河窄 | checkdmarc 已跟进 RFC 9989 | 主卖点放"条款账本 + 三方对账 + what-if"，不押"支持新标准" | 作者 |
| R3 对账输出被误读为"你被黑了" | 用户看到"头里 pass、我算 fail" | 每条矛盾 ≥2 解释 + 验证方法；`--strict-evidence` 禁词；authserv-id fail-closed | 作者 |
| R4 零依赖 RSA 实现出错 | 自研 DER/PKCS#1 解析 | 与 `cryptography`（仅测试期）逐条对账；五类失败 fixture 含正/负样本 | 作者 |
| R5 确定性被环境破坏 | 键序 / 浮点 / 时钟 / 路径 | K2/K7/K8/K9 + AST 守门 + 双跑 diff | 作者 |
| R6 断言太弱（假门） | 门写了但抓不到故障 | 每条守门配一组变异验证（`plan/05` §3） | 作者 |
| R7 范围蔓延 | 实现中想加功能 | `docs/backlog.md` 登记，先改题面再改口径 | 作者 |

## 5 决策记录（本棒新增）

| # | 决策 | 备选 | 理由 |
|---|---|---|---|
| D1 | 零运行时依赖（自实现 RSA 原语） | `cryptography` | CI 四矩阵不缺包、发布件自足、离线装包不受代理影响；Ed25519 明确降级为 `undecidable` |
| D2 | `requires-python = ">=3.11"` | 降到 3.9 | 照题面 §1；本机 3.12 通道开发，3.11/3.13 由 CI 覆盖 |
| D3 | 本棒不建远端 | 立即 `gh repo create` | 本轮只交付"计划 + 骨架"；脱敏四步属发布棒 |
| D4 | 平铺 `mailvault/` 而非 `src/` | `src/` 布局 | 题面 §8 目录约定是规格 |
| D5 | argparse `SystemExit(2)` 统一转 3 | 保留 2 | 与 `undecidable` 的退出码 2 语义冲突 |
| D6 | 未实现子命令返回 `MODULE_NOT_READY` + exit 2 | 直接报错/静默成功 | fail-closed；"没做"不能长得像"通过" |
